# Custom Recipes

## Overview

The Life Series has a couple of custom recipes:


### Alternative TNT Recipe
*The default TNT recipe is still available.*
![recipe_tnt.png](/recipe_tnt.png)

### Spawner Recipe
Disabled by default in most seasons
![recipe_spawner.png](/recipe_spawner.png)

### Bundle Recipe
Only available in 1.20-1.21.3, since after that, bundles are craftable in vanilla Minecraft with the same recipe.
![recipe_bundle.png](/recipe_bundle.png)

### Saddle Recipe
Only available in 1.20-1.21.5, since after that, saddles are craftable in vanilla Minecraft with the same recipe.
![recipe_saddle.png](/recipe_saddle.png)

### Name Tag Recipe
Only available in 1.20-1.21.11, since after that, name tags are craftable in vanilla Minecraft with the same recipe.
![recipe_nametag.png](/recipe_nametag.png)

### Moss Block Recipe
Only available in Last Life.
![recipe_mossblock.png](/recipe_mossblock.png)

### Spore Blossom Recipe
Only available in Last Life.
![recipe_sporeblossom.png](/recipe_sporeblossom.png)

### Magma Cream Recipe
Only available in Limited Life.
![recipe_magmacream.png](/recipe_magmacream.png)

## Customizability

For now, most custom recipes cannot be turned off, with the exception of the spawner recipe.

The spawner recipe is only enabled by default in Secret Life and Wild Life.

The spawner recipe can be disabled or enabled in the [Config](/config/overview).
