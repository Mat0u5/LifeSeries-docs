Re-made and added all the youtuber snail skins as pre-built skins.

----------

Heart color based on lives is now available in 1.20 as well.

----------

Added the new '/snail textures preset' command. [More info here](/commands/detailed/snail.html#snail-textures-preset)
Added the 'wildcard_snails_random_preset_skin' wild life config, which automatically randomizes the snail skin preset setting for any joining player (if they do not have a custom skin already).

----------

Snails and Trivia bots now have improved ice walking physics.
You can no longer get the same effect twice in one roll from the trivia bot.

----------

Added an optional 'all' argument to '/wildcard effect activate' which shows the rainbow title.
Fixed the additional wither skull drop throwing an error in the console.

----------

The Secret Society now properly shows the 'Do not read out loud ....' message.
Added the 'LimitedLife' scoreboard which has time values in seconds for certain actions.

----------

Fixed the hunger wildcard removing non-default components of items.
Added the '/nicelife forceSleep' command, which triggers trivia even if some players are not in bed.

----------

Added an 'empty' wildcard. It is not activated anywhere as normal wildcards can (except Callback all wildcard activation), it can only be activated via the wildcard command ('/wildcard activate empty'), where it is not suggested as a valid option on purpose.

----------

Added the 'trivia_show_nonsleeping' Nice Life config. Default value is false. Displays players that are not sleeping yet when you are in bed.
Fixed Forge and NeoForge launch mixin crash issue.

----------

Added the 'public_voting' Nice Life config. Default value is false. Shows the number of votes for each player has.

----------

Switched the mod custom sounds namespace from 'minecraft:' to 'lifeseries:'

----------

You can now specify '/session timer set infinite' to have an infinite session, however this may cause some issues with specific time related features.

----------

You can now run '/session start finale' to activate a finale session. This session will be infinite and will have any finale specific features.
Wild Life finale - callback will be activated + wildcard nerfs.
Secret Life finale - players are give the 'Win Secret Life' task.

----------

Added the '/zombie ⟨player/s⟩ ⟨location⟩' command which lets you spawn dead players as zombies in Wild Life.
Added the 'soulbound_lives_assign_match' Double Life config. Default value is false;

----------

Added the 'final_death_title_match_death_message' global config. Default value is false.

Pre-built snail skins now work properly in <= 1.21.1
Added the ability to have custom Trivia Bot textures per player.

----------

The Side-Title now works properly in 26.2+
Added the 'wildcard_mobswap_boss_spawn_cutoff' Wild Life config, which controls after which point in the session bosses can spawn. Default value is 0.7 (70%)
