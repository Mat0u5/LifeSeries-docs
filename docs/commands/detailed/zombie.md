#  `/zombie` Command

Manually summon Zombies in Wild Life.

::: info Availability
This command is only available in **Wild Life**.
:::

---

## Commands

<div class="command-block">

### `/zombie`

This command lets you spawn dead players as zombies.

```
/zombie <player/s>
/zombie <player/s> <location> - spawns the zombie at a specific place
```

**Permissions:** Operator
